# 5–7 minute demo
1. Introduce the monitoring problem and objectives.
2. Show the team profile and click Save profile (stored in the browser).
3. Point at the mode banner, click Collect updates; explain that every record is an illustrative sample.
4. Search/filter cloud updates and open source links.
5. Analyze one update; explain profile + memory + update inputs.
6. Generate digest and explain priorities/actions.
7. Add team memory (e.g. “Container workloads use Kubernetes and Terraform”) and rerun analysis to demonstrate contextual retrieval.
8. Show evaluation counts/distributions and clarify what metrics do not prove.
9. Open `/docs`; show endpoints.
10. End with limitations and future work.

Screenshots: dashboard, collection results, updates filters, analysis card, digest, memory entries, evaluation page, Swagger docs.

## Optional: question answering
Open **Ask a question**, click an example question (for example the Kubernetes one) and show that the answer lists numbered sources and the illustrative-sample notice. Then ask something unrelated (for example about Oracle) to show that no answer is invented.
